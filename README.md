Hikar Webapp
============

This is the repository for the [AR.js](https://github.com/AR-js-org/AR.js) based Hikar web app, which aims to port the [Hikar](https://hikar.org) Android app to the web. 

### IMPORTANT!

This is the OLD version. It is based on "classic" location-based AR.js and A-Frame, but does not support iOS and will not see any further development. 

Please see [https://github.com/nickw1/hikar-locar](https://github.com/nickw1/hikar-locar) for the new Web version of Hikar.
